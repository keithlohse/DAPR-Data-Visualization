1 Static Data Visualization

In this section, we walk through the iterative process of building data visualizations. We start with raw observations, layer on aesthetic mappings and summary geometry, aggregate data to account for repeated measures, and conclude with multi-panel publication figures.

1.1 Step 1: Raw Geometry (The Foundation)

We begin by mapping Surface condition to the x-axis and PathLength_Total to the y-axis. This raw point plot reveals the basic distribution of data but suffers from heavy overplotting across conditions.

It is worth noting that plotnine is a package for Python that uses syntax essentially identical to ggplot in R (both plotnine and ggplot are based on Leland Wilkinson’s “Grammar of Graphics” - a layered system to build data visualizations). However, when making this document using Quarto inside of R Studio, I need to call Python functions using reticulate and - for computing reasons I do not full understand - it is difficult to render plotnine objects through reticulate. Thus, for these examples, I am using matplotlib and seaborn to great plots similar to my ggplot visualizations, but for pragmatic users, it is probably more efficient to learn ggplot/plotnine syntax that is portable across languages.

  • R (ggplot2)
  • Python (matplotlib & seaborn)
Show Code 
library(tidyverse)
library(patchwork)
library(GGally)

DATA <- readRDS("./data/BDS/output/BDS_trial_summary.rds") %>% 
  mutate(Subject = factor(Subject),
         AgeGroup = fct_relevel(AgeGroup, "Young", "Old"))

# Plot 1: Basic scatter plot
ggplot(data = DATA, aes(x = Surface, y = PathLength_Total)) +
  geom_point()

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

DATA = pd.read_csv("./data/BDS/output/BDS_trial_summary.csv")
DATA["AgeGroup"] = pd.Categorical(DATA["AgeGroup"], categories=["Young", "Old"], ordered=True)

# Step 1: Basic scatter plot
fig, ax = plt.subplots(figsize=(6, 4))
sns.scatterplot(data=DATA, x="Surface", y="PathLength_Total", color="black", ax=ax)
ax.set_ylabel("Total Path Length (cm)")
sns.despine()
plt.show()

1.3 Step 3: Layering Jittered Points, Boxplots, and Custom Palettes

To better summarize central tendency and spread, we overlay boxplots beneath jitter-dodged raw data points and apply a high-contrast, colorblind-friendly palette.

1.4 Step 4: Subject Aggregation & Visual Polish

Because individual trials introduce nested variance, we aggregate data to subject-level means (AVE_DATA). We also refine labels, typography, and legend positioning to polish the figure.

  • R (ggplot2)
  • Python (matplotlib & seaborn)
Show Code 
# Aggregate trial data to subject-level averages
AVE_DATA <- DATA %>% 
  select(-Trial) %>%
  group_by(Subject, Vision, Surface) %>%
  summarise(
    across(where(is.numeric), ~ mean(.x, na.rm = TRUE)),
    across(!where(is.numeric), dplyr::first),
    .groups = "drop"
  )

# Plot 4: Formatted subject-level summary
ggplot(data = AVE_DATA, aes(x = Surface, y = PathLength_Total)) +
  geom_point(aes(shape = Vision, col = Vision),
             position = position_jitterdodge(dodge.width = 0.5, jitter.width = 0.2),
             alpha = 0.5) +
  geom_boxplot(aes(fill = Vision), width = 0.5,
               position = position_dodge(width = 0.5),
               alpha = 0.5, outlier.shape = NA) + 
  scale_color_manual(values = cbPalette[c(1,2)]) + 
  scale_fill_manual(values = cbPalette[c(1,2)]) +
  theme_bw() +
  labs(
    title = "Postural Sway: Total Path Length by Surface and Vision",
    subtitle = "Mean values aggregated across trials per subject",
    x = "Surface Condition",
    y = "Total Path Length (cm)",
    shape = "Vision Condition", 
    col = "Vision Condition",
    fill = "Vision Condition"
  ) +
  theme(
    axis.title = element_text(size = 12, face = "bold"),
    axis.text = element_text(size = 11),
    legend.position = "bottom",
    plot.title = element_text(size = 14, face = "bold"),
    plot.subtitle = element_text(size = 12, face = "italic", color = "gray30")
  )

1.6 Step 6: Incorporating Between-Subject Factors (AgeGroup)

Next, we evaluate how age group interacts with balance conditions. We plot the combined interaction (Surface:Vision) along the x-axis and facet by AgeGroup.

  • Python (matplotlib & seaborn)

AVE_DATA <- AVE_DATA %>% 
  mutate(Condition = interaction(Surface, Vision, sep = ":"))

1.7 Step 7: Multivariate Correlation Matrix

To examine multicollinearity among extracted postural metrics across age groups, we build a scatterplot matrix containing bivariate scatter plots (lower triangle), density distributions (diagonal), and correlation coefficients (upper triangle).

  • R (GGally)
  • Python (seaborn)
Show Code 
plot_data <- DATA %>% 
  select(AgeGroup, PathLength_Total, PathLength_ML, PathLength_AP, EllipseArea95) 

# Plot 7: Correlogram matrix
ggpairs(
  data = plot_data,
  columns = 2:5,
  mapping = aes(color = AgeGroup, fill = AgeGroup),
  lower = list(continuous = wrap("points", alpha = 0.3, size = 1.2)),
  diag = list(continuous = wrap("densityDiag", alpha = 0.3)),
  upper = list(continuous = wrap("cor", size = 4))
) +
  theme_minimal() +
  scale_fill_manual(values = cbPalette) +
  scale_color_manual(values = cbPalette) +
  theme(
    panel.grid.major = element_blank(),
    strip.text = element_text(face = "bold")
  )

#| label: script02-r-plot4

AVE_DATA <- DATA %>%
